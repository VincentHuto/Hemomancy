# Memory recipe cost ledger

Generated by `python tools/manipulation_recipe_ledger.py` from current recipe resources.
85 ordinary recipes and 5 alternatives. Prices are unchanged pending M18–M25 combat tuning.

Every row additionally needs **one blank**: four Sanguine Formations, four Blood-Stained Stone and one Neurotic Enzyme.
The lantern estimate includes that blank enzyme: 600 mL and two minutes per enzyme, plus weaving blood.
Culture and catalyst acquisition, infrastructure, absorption and blood regeneration are excluded. Looted enzymes can bypass lantern production; parallel lanterns reduce elapsed time.
These are minimum successful costs: weaving drift can spend extra enzymes, and cancellation does not refund spent blood/enzymes.
An alternative replaces its ordinary weaving recipe; it is not an extra required purchase. Family capstones need baseline mastery and their own memory, not every intermediate memory.

Crude alternatives cost 500 mL to learn and bypass weaving: Blood Shot, Blood Rush, Deadly Gaze, Sanguine Mending, Hemorrhage, Glacial Grasp, Sanguine Ignition and Void Shroud.
Staff grafts, Degree-I utility grants, Vesper's memory and Thread Ripper use separate routes documented in [area 3 results](03-acquisition-results.md).
