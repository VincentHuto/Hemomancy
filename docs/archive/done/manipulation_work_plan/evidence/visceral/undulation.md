# Organic contour capture study

Local-space undulation with the approved 32-pixel materials and blood-cell/glow accents. The integrated-client fixture exercises production visual packets; these images do not constitute a new dedicated-server combat test.

Each sequence shows formation (15), early release (31), active effect (41), fading (66), and cleared state (80). The frontal Crown view deliberately retains the close player viewpoint; the offset view shows more of the crown silhouette.
