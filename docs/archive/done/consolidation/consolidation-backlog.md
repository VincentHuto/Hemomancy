## Suggested first three reviewable changes

1. **Documentation-only contract:** add the Alembic/Retort slot, bar, click, and tooltip geometry table to [screens and menus](screens-menus-and-sprites.md). This exposes mismatches before a shared UI helper is written.
2. **Small runtime extraction:** share only the distillation output-capacity predicate. Leave input consumption and fluid logic in each block entity. Compare results carrying data components before deciding whether `isSameItem` should remain the compatibility rule.
3. **Lifecycle cleanup:** coordinate the three Unstained zone expiry passes while leaving their effect handlers and saved-data types separate. Inspect world reload and expiry at the saved-data boundary.

After each change, verify the directly affected gameplay path. Recipe/machine changes need actual inventory and fluid behavior; menu changes need live GUI scale and hover checks; rite changes need save/reload and multiplayer scope. The user's requested work here is the documentation and audit, so this backlog does not assert that any extraction has already been implemented.
