# Annetta Encounter Models Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (user preference: native execution, one final reviewer). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three placeholder box models of the Annetta encounter with five scripted, painted, rigged looks (cowering, purged ally, Phase 1, Stained Priestess, Latent Infection) without changing encounter gameplay.

**Architecture:** One Python script per entity under `tools/model_export/` emits a generated `HierarchicalModel` Java class plus painted 2× textures and a preview PNG, sharing a small kit module. Hand-written renderers pick textures and part visibility from a pure `AnnettaLooks` rules class keyed on the entity's existing synced state. A gameTest review client captures in-game screenshots of every look.

**Tech Stack:** Python 3 + Pillow + numpy (existing model_export pipeline), NeoForge 1.21.1 vanilla `HierarchicalModel`/`MobRenderer`, JUnit 5, `java_model_to_bbmodel.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-15-annetta-encounter-models-design.md`

## Global Constraints

- Hitboxes: Annetta 0.6 × 1.8 (unchanged); Stained Priestess 0.9 × 2.2; Latent Infection 2.5 × 4.5.
- Visual sizes: Priestess body ~2.2 blocks (≈35 model units), each wing ~5 blocks (≈80 units) fully spread; Latent Infection ~5 blocks tall (≈80 units, may be built at half size and rendered at 2× like `MycophantRenderer.scale`).
- Copper/verdigris allowed only on Annetta's human looks and the cracked shield. No copper, brass, bronze or silver on the Priestess or Latent Infection.
- Cowering/Phase 1: long red hair, gold eyes, nothing else visibly infected (except the Phase 1 tick). Purged: short white hair, blue eyes.
- Purged ally carries only her dagger (no shield); healing pose on `VISUAL_CURED_SUPPORT`: off hand raised open toward the player, dagger hand held back.
- Equipped render items (`annettas_absolution_dagger`, `annettas_sanguis_lancea`) get `setDropChance(slot, 0.0F)`.
- No AI, damage, drop-table or progression changes. Only equipment changes: Phase 1 and cure route equip `annettas_absolution_dagger`; Priestess equips `annettas_sanguis_lancea`.
- Generated Java files carry the header comment `/** Generated by tools/model_export/<script>.py; edit the rig there and re-run it. */`.
- No vanilla particle clouds added. Glow uses `RenderType.eyes` layers.
- Use NeoForge imports, `Hemomancy.rloc`, 4-space indentation as in the existing `boss/annetta` files.

## Review Focus

1. Mainhand equipment drop chance: a Phase 1 Annetta killed by a player or a Priestess killed must not drop an extra dagger/lancea (default mainhand drop chance is 0.085). Test: `AnnettaModelSourceTest.equippedRenderItemsNeverDrop` (Task 2/3).
2. Old saves: an Annetta saved in `PHASE_ONE` or `CURED_SUPPORT` before this change holds the plain `absolution_dagger` or nothing; the renderer must not crash and should still show the right look. Test: `AnnettaLooksTest.looksDependOnlyOnState` (Task 2) — looks never read the held item.
3. The Latent Infection spawned inside the broken church must not suffocate with its new 2.5 × 4.5 box. Test: `AnnettaModelSourceTest.cureRouteChecksInfectionSpace` (Task 4) asserts the spawn goes through `level.noCollision(infection)` search before `addFreshEntity`.
4. Tick swell at full health is small but visible, and never exceeds the grotesque max at 0 health. Test: `AnnettaLooksTest.tickSwellRange` (Task 2).
5. Wing span blowing out culling: the Priestess renderer must widen `getBoundingBoxForCulling`/`shouldRender` so wings don't pop out at screen edges. Test: `AnnettaModelSourceTest.priestessCullingCoversWings` (Task 3).

### Task 1: Shared model kit

**Files:**
- Create: `tools/model_export/annetta_kit.py`

**Interfaces:**
- Produces:
  - `class Rig(name: str, java_class: str, layer: str)` with `part(name, parent='root', pivot=(0,0,0), rotation=(0,0,0)) -> str`, `cube(part, box, material, **extra)`, `mirrored(part, box, material, **extra)` (x-flipped onto the `right_`/`left_` twin, as in `vestment_of_the_final_molt.Rig.mirrored`).
  - `layout(rig, width: int) -> (int, int)` — box-UV packer like `unstained_weapons.layout` but with caller-chosen width (64–512) and heights up to 1024.
  - `paint_atlas(rig, size, painter, scale=2) -> (Image, Image)` — like `unstained_weapons.paint_atlas` but writes `scale`×`scale` px per texel (2× painted textures; the Java atlas size stays in model units).
  - `entity_java_source(rig, size, package: str, entity_class: str, script: str, armed: bool, extra_fields='', extra_ctor='', extra_methods='') -> str` — emits `public class <java_class> extends HierarchicalModel<<entity_class>>` (plus `implements ArmedModel` when `armed`), `LAYER_LOCATION = new ModelLayerLocation(Hemomancy.rloc(layer), "main")`, `root()` override, a field for every named part (camelCase), and leaves `setupAnim`/`translateToHand` to `extra_methods`.
  - `preview_sheet(rig, texture, views: list[(yaw, pitch)], hidden=(), out: Path)` built on `unstained_weapons.rig_quads`/`render_quads`.
  - Palette helpers re-exported from `unstained_weapons`: `h, add, mix, verdigris, linen, silver`; new `flesh(t)`, `vessel(t)`, `fungus(t)`, `infected_ichor(t)` (yellow-orange `(214,150,48)` → `(168,92,30)`), `blood(t)` (`(118,18,24)` → `(70,8,14)`).
