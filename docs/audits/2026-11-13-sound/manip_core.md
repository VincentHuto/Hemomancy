# Sound audit: Core manipulations, verbs, Ferric, Flammeus

Part of the [2026-11-13 sound audit](README.md). Search links open Freesound filtered to CC0.

## Notes

- ManipulationCastSounds maps about 40 manipulations onto 19 vanilla cues through a switch, and many share one cue (blood_shot/guided/halo/mortar, needle/fan/lance, conjure_staff/blood_absorption/blood_projection, iron_choir/lodestone_collapse, furnace_veins/searing_lash, white_verdict/radiant_wake, carrion_communion/fruiting_contagion, rimebound_sentence/cruor_javelin, blood_rush/umbral_rend, activation_potential/synaptic_storm). Replace the enum with a per-id lookup of manipulation.<id>.cast so each one sounds different. The rows above name the first id of each group and say what the others need.
- Manipulations with no entry in that table (default -> null) are silent on cast unless their class plays something itself. One example is blood_cloud, which uses levelEvent 1016 (the ghast shoot sound) and so is not in the calls file. The manip_schools slice should check each class.
- EntityCasts repeats each manipulation's player-side sound with different vanilla constants. Entity and player casts of the same manipulation should share one event, and the rows merge the moments that are identical.
- Several moments stack two vanilla sounds on the same tick: Vitric Combustion, Cauterizing Rebuke, the Pyretic Forge R cast, Lodestone Collapse, the lash crack and Searing Lash. Each should become one layered file.
- FerricRunShaping retriggers GRINDSTONE_USE every 6 ticks, and PyreticForgeShaping retriggers FIRE_AMBIENT every pulse. Both want real loops (a client SoundInstance), not retriggered one-shots.
- FlameKindleShaping:113 plays flint-and-steel on top of TNT priming, which already plays its own primed sound. It can simply be dropped.
- The strand family (lash, jet, spray, plant, brand) only makes a sound on the crack, tap, ambush, eruption and brand. The lash's charge orb, throw, swing, snap and recall are silent, and so is every jet and spray pulse. Lashes from different schools (Blood Lash, the Searing Lash strand, Gloam Laceration) all share the generic lash sounds with no school layer. Add a per-school layer event (manipulation.lash.<school>_layer) so a fire lash does not sound like a plain one.
- Plain Blood Projection and Blood Absorption, the two verbs the player holds most, make no sound at all while held. Only the cell-hand conjure plays, and it uses HOGLIN_CONVERTED_TO_ZOMBIFIED at 0.2 volume.
- Phoenix Debt, a Perfectus death-save, makes no sound when it fires (ManipulationReactiveEvents:274).
- hematic_riposte.parry borrows the bow blade's stereo clang, so a positional sound plays from a 2-channel file. All three riposte events need their own mono files.
