# Mod cleanup audit, 2026-11-02: consolidated ledger

Eleven read-only audits of `neo-1.21.1` at `8d01a316c` (ten areas plus a books-and-tooltips sub-audit), each written by its own agent against the code and
data (not the docs). This file is the roll-up: what to fix now, what to cull, what to finish, what to merge, what needs
the user's call, and what has never been watched in a client. Each line cites the finding id in its report; the report
holds the evidence (`path:line`), the method and a "Not a problem" section of things already checked, so the next
session does not re-check them.

Nothing was built, run or edited by the audits. Two things were changed by the coordinating session: the two stale
staged files `MorphlingCamouflageRules.java` and `MorphlingColdResilienceRules.java` were dropped from the git index
(their declared class names did not match the file names and nothing referenced them; RF-9 / DC-78), and a stray
`grep.exe.stackdump` was removed from the repo root. `compileJava` and `compileTestJava` passed at the start of the
pass.
