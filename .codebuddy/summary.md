# Project Summary: Hemomancy

## Overview of Technologies
The Hemomancy project is developed primarily in Java, leveraging the Minecraft Forge framework for modding Minecraft. The project utilizes various libraries and resources to create a rich gaming experience, including custom models, animations, shaders, and textures.

### Languages and Frameworks
- **Java**: Main programming language for mod development.
- **Minecraft Forge**: Framework used for creating mods in Minecraft.

### Main Libraries and Assets
- **Modeling Libraries**: Custom models for entities, blocks, and items.
- **Animation Libraries**: JSON files for animations and model behaviors.
- **Shader Libraries**: GLSL shaders for visual effects.
- **Texture and Asset Libraries**: PNG and JSON files for textures and block states.

## Purpose of the Project
The Hemomancy project aims to introduce a new gameplay mechanic centered around blood magic and manipulation within the Minecraft universe. Players can engage with new items, blocks, and entities that revolve around the theme of blood, enhancing the overall gameplay experience with unique features and lore.
